# 点调整（PA）使用篇数统计

## PA - Point Adjustment定义

定义（论文 l.047）：一个异常区间里只要有任何一个点报了警，整个区间就都算检测到了。

标签：  0 0 1 1 1 1 1 0
报警：  0 0 0 0 0 0 1 0     ← 只在最后一个点报了警
PA 后： 0 0 1 1 1 1 1 0     ← 整段都算对，F1 直接变满分

## §2 论文正文怎么说 PA 普遍性

### 2.1 正文原句

- **l.012–014（摘要）**：「common evaluations define pre-onset targets by temporal proximity and apply point adjustment, allowing reactive detections to receive credit as apparent predictions.」
- **l.026–028（摘要）**：「Point adjustment raises mean pre-onset Shifted-warning F1 from 0.036 to 0.177 without changing any alarm time」。
- **l.047–050（引言）**：「Another common evaluation practice further compounds this problem. Point adjustment counts an entire positive segment as detected if an alarm occurs anywhere within it (Su et al., 2019; Zhao et al., 2024; Lee et al., 2023; Kim et al., 2022; Wu & Keogh, 2023; Sarfraz et al., 2024; Wagner et al., 2023).」
- **l.082–084、l.092–095（贡献）**：「extending anomaly labels into the pre-onset period and applying point adjustment are insufficient」；「systematic F1 inflation under point adjustment」。
- **l.130–133（相关工作 2.3）**：「point adjustment may substantially inflate performance by counting an entire segment as detected after a single hit (Kim et al., 2022; Sarfraz et al., 2024; Wagner et al., 2023)」。
- **l.247–248（3.4）**：「In post hoc detection, point adjustment tolerates small misalignments... (Su et al., 2019; Kim et al., 2022)」。
- **l.251–253**：「RQ3 evaluates PA only as a credit rule for early warning.」

正文没有给出「N 篇论文用了 PA」这样的数字，也没有写「大多数」「X% 的检测器」这类量化说法。「common」「commonly」只是定性词。

### 2.2 与 §0 统计的对照

- l.047–050 引的 7 篇里，各篇在本统计中的归类如下：

| 引用 | 本统计归类 |
|---|---|
| Su 2019（OmniAnomaly） | 主结果用 |
| Zhao 2024（FCM） | 主结果用 |
| Lee 2023（Maat） | 主结果用（段级变体） |
| Kim 2022 | 批判对照 |
| Sarfraz 2024 | 批判对照 |
| Wu & Keogh 2023 | 提取无 PA 记录（没写） |
| Wagner 2023 | 本次未提取，没有证据 |

- 4 篇检测论文（USAD、AT、DCdetector、MEMTO）在本统计里正式采用 PA，但 l.047–050 没有引它们；正文只引了 Su 2019 一篇检测论文。
- l.034–036 把 AT、TranAD、MEMTO 等列为 reactive 检测器，该句讲的是 reactive，不是 PA。
- 预警类内部：l.012–014 说「common evaluations ... apply point adjustment」，对应的预警类证据是 1 篇明写（FCM）、2 篇变体 / 等价（Maat、FATE）、1 篇软化（A2P）、3 篇明确拒绝（MultiRC、RED-F、IGCL）、2 篇没用或没写（you2024、PAD）。

结论：
- 正文只说 PA 是常见做法，没有给篇数，所以与 §0 的统计没有数字冲突。
- 能直接核对的部分是引用归属：l.047–050 引的 7 篇中，3 篇有「采用」证据（Su、Zhao、Lee），2 篇是批判对照（Kim、Sarfraz），Wu & Keogh 与 Wagner 在本次提取里没有 PA 证据。

## §3 存疑条目

1. **TimesNet**：论文正文与附录全文无「point adjust」字样，阈值选法也没写。官方代码用 PA，但论文没写，只能引代码，不能引论文正文说它用 PA（xlsx 重要提醒 4；08 号提取）。归「没写」。
2. **TranAD**：论文文本没写点调整，只有代码沿用含 PA 的评估管线（01 号提取）。归「没写」。
3. **Wu & Keogh**：l.049 把它放在 PA 引用里，但本次提取（03 号）没有记录它对 PA 的论述。该论文是否讨论 PA 需回 PDF 核（`wu2023current.pdf`）。
4. **Wagner et al. 2023（TimesEAD）**：l.049、l.133、l.140 三处引用，但 `wagner2023timesead.pdf` 在 `reference/` 里、没有进 raw_extracts，本次没有证据。
5. **Huet 2022**：提取只记「PA 可被对抗算法打爆」这一主张，没有它自己是否计算 PA 数字的记录。
6. **Maat**：「段级调整（Donut 式点调整变体）」。其原句是把整个窗口标为异常，是否等同标准 PA 需核；本表算作「变体」，没有并入严格口径。
7. **FATE**：xlsx 表4 写「F1₀ 自认等价 PA」。提取里没有逐字原句，需回 `kang2026fate.pdf` 核「F1₀ = PA」是原文原话还是提取者的归纳。
8. **A2P**：tolerance-t F1，t→∞ 等价 PA，默认 t=50。是软化版，不是标准 PA，不计入「用了」。
9. **PAD**：「未提点调整」且阈值选法 [未找到]，归「没写」。xlsx 表4 对应格是「未说明」。
10. **38 vs 39**：xlsx 说明页和主文档写 38 篇，逐篇列出实为 39 条。USAD 原 PDF 是错文件，后来从 EURECOM 镜像重下并补提取（09 号提取），差 1 条疑与此有关。`reference/` 目录里有 47 个 PDF，其中 `bury2023predicting`、`feng2024sensitivehue`、`huang2024rate`、`wagner2023timesead`、`wang2023drift`、`wang2024cutaddpaste`、`wu2025catch` 7 篇没有进 raw_extracts（`darban2025survey` 也没有提取记录，不过它是综述）。若分母要以「参考文献全体」为准，需另行核对。
11. **页码**：本表的证据为章节 / 表号，没有 PDF 页码。
12. **TranAD / USAD 的 SWaT 无 PA 数字**：USAD Table 2 同表有 / 无 PA 两版是文献里少数能直接对照的证据，数字见 xlsx 表2b。本统计只管「用没用」，不引这些倍数。
