# 按时间远近定义预警目标的论文篇数 · 有没有检验过前兆存在

日期：2026-11-10。只读统计，只写本文件，没改论文和其他任何文件。

**问题**（张赢原话）：「常见做法是按时间远近，把 onset 前紧挨着的那几步直接标成正例。这等于默认每个事件之前都有前兆，但从来没检验过。需要找一下有多少文章存在这种问题。」
对应冻结稿 l.043–045：「a common evaluation protocol labels the time steps just before each event onset as positive (Zhao et al., 2024; Kang et al., 2026) … The protocol thus assumes that every event is preceded by a precursor, without testing this assumption.」

**口径**
- 只有读过方法节和评估节的才计数；只看了摘要的放 §3，不计。
- 目标类型：**A** = 把 onset 前 H 步（或前一个窗口）改标成正例；**B** = 预测未来 H 步内会不会出异常（look-ahead 窗口标签）；**C** = 先预测未来的值，再逐点检测，标签仍是原始逐点标签；**D** = 其他。A 和 B 在时间步上等价，区别只在原文怎么表述：A 说「改标签」，B 说「预测未来窗口」。**A + B 就是「按时间远近定义正例」。**
- 前兆检验：**有** = 系统检验过事件前的数据是否异于正常（匹配的正常窗口 / null 序列 / surrogate 对照、统计检验、逐事件判有没有前兆）；**部分** = 只在合成数据上人为造前兆、只挑个例、只口头承认、或逐事件数过但没和正常对照；**无**。
- 评估区间和记分规则两列是 zhangying-d2 后加的，对应 RQ3：**P** = 只有 onset 前那段（Shifted）；**P∪A** = 前后合并（Merged）；**A±容差** = 原始异常段两侧带容差；**A** = 只有异常段。记分：标准 PA / 类 PA（段级变体、tolerance-t、事件级「任一报警即命中」、early reward）/ 逐点（逐窗口、逐样本）/ 指标自定义。

**证据来源与核查**
- 库内 18 篇：我逐篇回 PDF 核了原文句，页码是 PDF 页。
- 库外 28 篇：两个子 agent 分 ML 词、领域词两轮检索，读了全文。我对照它们下载的原文抽查了约 35 条引句，全部能找到（个别句子被双栏排版打散，内容一致）。没抽到的引句以 agent 摘录为准，标了「待核」的不要直接引用。
- 库外 PDF 和抽出的文本在 scratchpad（`ext_ml/`、`ext_domain/`），**没有入库**。要在 rebuttal 里引用，先走 `_Literature/_tools/ingest-paper.sh`。

  - 「无」的 6 篇：FCM、PNEUMA、StreamDFP、PAD、MTS-JEPA、Cerqueira。
- **时序异常预测 ML 论文的 A + B 共 11 篇，检验过的 0 篇**：FCM、IGCL、PNEUMA、MCDA、PAD、MultiRC、MTS-JEPA、you2024、TranAP、Cerqueira、Pinciroli Vago。最接近的是 MCDA：它把紧挨异常前的 bag 和正常期随机抽的等长 bag 做 1:1 对照，但只用在专家**预先标好有前兆**的 5 个 case 上。
- **D 类里另有 5 篇也按时间远近定义前兆或给分**（FATE 的 early reward、D-HTM 的「onset 前 L 步 = 前兆记忆」、Bleu-Laine 的进近段、Boixaderas 的 24 h 窗、Ayodeji 统一的「失效前 130 cycles 开始退化」），都没有系统检验。
- **检验过的 8 篇结论不一，不能笼统说「都没有前兆」**：
  - **相当一部分事件测不到前兆，或信号接近随机（4 篇）**，可作 rebuttal 旁证：
    - Pinciroli TDSC'21：故障盘最后 7 天没有任何错误的概率约 75%。
    - Pinto 2021：surrogate 检验下只有 32% 的患者高于机会水平。
    - Dylewsky 2023：AUC 从 90% 到低于 50%，并写明「many of the included transition events are not preceded by any signatures」。
    - agent failure（2610.05572）：同任务内配对后，早期监控 AUROC 只有 0.50–0.55。
  - **前兆起点因事件而异，固定 H 标注会出错（1 篇）**：
    - Ai et al.：固定 25 / 50 / 100 ms 标正例的 FPR 是 5.45 / 9.09 / 13.64%，逐 shot 推断起点后为 3.64%。
  - **在受控或模拟系统上测到了前兆（3 篇）**：
    - Bury 2021、Bury 2023：对照 null 序列，AUC 高。
    - Huang 2024：深度模型在转变前 280 步内能把 tipping 组和非 tipping 组区分开，但临界减速（CSD）区分不了。
  - 这 8 篇的共同点不在结论，而在**做法**：都是先拿 null 或正常对照检验，而不是默认前兆存在。
  - 另有几篇逐事件数过「有没有前兆」但没做对照（计为「部分」）：
    - Yu DSN'24：sudden UE 占 18–58%，并被直接剔除。
    - Boixaderas：67 个 UE 里 25 个事前 24 h 没有任何日志。
    - Outage-Watch：30–50% 的 outage 在指标上不显现。

**zhangying-d2 追加的问题：「P∪A 上用 PA / 类 PA」在预警论文里是否真实存在？**
- **P∪A + 标准 PA：46 篇里 0 篇。**
- **P∪A + 类 PA：有原文的 1 篇，Outage-Watch（ESEC/FSE'23）。**
  - 离线标签是 look-ahead 窗口，没剔除事件进行中的输入。
  - 部署评估按 outage 宣告时刻 C 计「提前量」，三次「正确预测」的 MTTD 缩减都小于 100%（54 / 76 / 27%）。按它自己的公式 (C − 预测时刻)/(C − B)，三次报警都发生在 B（指标开始受影响）之后。
  - 前提：要把 onset 定义为 B 而不是 C。
  - 另有 2 篇**待核**：StreamDFP、MVTRF 是 P∪A 标签加盘级 recall，但「一块盘任一天报警即算」原文没写。
- **Shifted（P）+ 标准 PA：只有 FCM 一篇。**
- 其余类 PA 的论文，要么只在 P 上用（Cerqueira、Ai、Li、Yu、Boixaderas、Pinto；都把 onset 后的报警排除在外），要么只在 A 两侧加容差（A2P ±50 步、FATE、PISCES），都不会出现「onset 后的命中把 onset 前那段记为预警」。
- 交叉表见 §2.5。

## §1 两条引用核查

### Zhao et al., 2024（FCM，arXiv 2410.12206）✅ 撑得起 l.043

- §4.1.1 p.5：「They are adapted to anomaly prediction task by shifting the ground truth of abnormal events to a proceeding window.」
- §4.1.3 p.5–6：「we designate the ground-truth labels of the window immediately preceding each true anomaly as anomalous. Also, for continuous anomalies, we only consider the first window in which the anomaly manifests. Subsequent anomalous samples within the same sequence are omitted from evaluation. Based on prediction results and the adjusted ground-truth labels, we employ the point adjustment strategy」
- H = 1 个窗口 = 100 步（stride 50，§4.1.4 p.6）。评估区间是 P，后续异常样本剔除；记分用标准 PA。这是 46 篇里唯一的 Shifted + PA。

### Kang et al., 2026（FATE，arXiv 2602.17028）❌ 撑不起「labels … as positive」

FATE 不改标签。§V-A p.8 写的是「unsupervised setting, where no anomaly labels are available」，测试集用原始异常段 A（§IV-A）。它是在**指标层**给 onset 前的报警加分：
- Eq. (10) p.7：「E(a, p′) = e^{−k(i′−ϵ)²}, i′ = t_a − i, where i < t_a」；「Here, i’ is the time gap between a precursor prediction and the start of the anomaly, ϵ denotes the optimal lead time … This formulation rewards timely predictions while penalizing those that are either too early or too late.」
- §V-C p.9：ε 按数据集调参（ε ∈ [1, 10]，PSM 峰值 ε = 7），k 固定为 0.001。核很宽：距 ε 30 步时奖励约 0.41。
- §V-D p.9：「To ensure fairness, we credit baseline models with early detection when they generate continuous anomaly scores prior to the true anomaly onset.」
- §VI-A p.9 主表 F1₀ 取 θ = 0，作者自认「aligns with the point adjustment strategy」。
- §VI-A p.10 作者自己承认：「these gains may be partially influenced by the reward mechanism for early detection」。

结论：FATE 撑得起 l.044「An alarm raised in this period then counts as an early warning, whether or not the data in the period differ from normal operation」的后半句，撑不起 l.043「labels … as positive」。参照表表 4 标的「❌ 完全无监督、不平移标签」是对的。
